SCADA / ICS Anomaly Detection System
📌 Overview

Developed an Industrial Control System (ICS) anomaly detection platform using Machine Learning and Splunk SIEM integration to detect cyber-physical attacks in SCADA environments.

The system analyzes industrial sensor telemetry from the SWaT dataset and identifies abnormal operational behavior using Isolation Forest, Random Forest, and LSTM Autoencoder models.

🚀 Key Features
ICS / SCADA anomaly detection
Behavioral analysis using ML
Time-series anomaly detection
51-sensor industrial telemetry analysis
Splunk HEC integration for SOC monitoring
Real-time anomaly alert generation
Severity-based incident tagging
🧠 Machine Learning Models
Isolation Forest
Random Forest
LSTM Autoencoder
